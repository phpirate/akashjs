# AkashJS

A TypeScript-first UI framework with Angular's structure and Svelte's simplicity.

## Install

```bash
npm install @akashjs/akashjs
```

## What's included

This package bundles the core AkashJS packages:

- `@akashjs/runtime` — Signals, components, DOM rendering
- `@akashjs/compiler` — `.akash` SFC parsing and code generation
- `@akashjs/vite-plugin` — Vite integration and HMR
- `@akashjs/router` — File-based routing with guards and loaders
- `@akashjs/forms` — Signal-based form management with validation
- `@akashjs/http` — Promise-based HTTP client with interceptors
- `@akashjs/i18n` — Signal-based internationalization
- `@akashjs/ui` — Material Design component library

## Quick start

```bash
npx @akashjs/cli create my-app
cd my-app
npm install
npm run dev
```
